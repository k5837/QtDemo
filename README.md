Aircraft war is a very interesting puzzle game. When the game starts, there should be basic game configuration, rolling background map, aircraft, randomly launched enemy aircraft, and audio addition.

 At the beginning of the game, players should drag the aircraft with the mouse to control the direction, and the aircraft cannot exceed the screen frame; Bullets are fired from the aircraft, and the enemy aircraft are also fired randomly from another direction of the screen. Collision detection is required from bullet firing to collision with the enemy aircraft. When bullets collide with the enemy aircraft, there will be time-sharing explosion effect. 

This game is based on qtcreator programming environment to realize the game.
